# 🎬 CuePin

## Om projektet

CuePin är en personlig streaming-dashboard där användare kan samla och organisera filmer och serier från olika streamingtjänster på ett ställe.

Målet är att göra det enklare att hålla koll på vad man vill se, vad man tittar på just nu och vilka favoriter man vill spara.

---

## Funktioner

* Lägg till filmer och serier
* Organisera innehåll i kategorier
* Filtrera mellan kategorier
* Spara favoriter
* Mobilanpassad design

---

## Kategorier

* 📺 Pågående
* ⭐ Vill se
* ❤️ Favoriter

---

## Teknik

Projektet är byggt med:

* React Native

* TypeScript

---

## Syfte

CuePin är ett personligt projekt som skapats för att utveckla kunskaper inom mobilutveckling, React Native och modern appdesign.

## Framtida funktioner

* Lokal lagring av data
* Detaljsidor för filmer och serier

## Installation

Installera beroenden:

npm install

Starta projektet:

npx expo start
